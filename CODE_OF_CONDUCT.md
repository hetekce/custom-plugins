# Code of Conduct

## Our standard

This project is a friendly, low-drama place to build small useful tools. We expect everyone
participating — issues, pull requests, discussions — to be respectful, constructive, and patient.

Be kind. Assume good faith. Critique code and ideas, not people. Welcome newcomers and answer questions
without condescension.

## Not acceptable

Harassment, personal attacks, discriminatory or demeaning language, sustained disruption, and
publishing others' private information.

## Enforcement

Maintainers may edit, hide, or reject contributions that violate this standard, and may block repeat
offenders. To report a problem, contact the maintainer via the email on their GitHub profile. Reports
are handled discreetly.

This is a lightweight adaptation of the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org). If the community grows, we'll adopt the
full text.
